Frequently Asked Questions

Does it require cutting bricks?

No. The system uses directional fields and fallback strategies to place units within standard dimensions.

Which Rhino versions are supported?

Rhino 8 (please confirm on the release page).

Can it calculate self-supporting structures?

The current version does not perform structural analysis. This is one of the main directions for future development.

How are openings handled?

Openings can be assigned separate starting curves. While intersecting polylines still need manual handling, future versions will automate this process.

About Porcupine

Porcupine is a Grasshopper plugin for arranging standard units on freeform surfaces, emphasizing buildability, continuity, and curvature conformity.
